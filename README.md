## Đưa lên GitHub Pages

1. Tạo repository trên GitHub.
2. Tải toàn bộ NỘI DUNG trong thư mục này lên repository. Đặt index.html ở ngay thư mục gốc cùng với assets và các trang HTML khác.
3. Trong Settings → Pages, chọn Deploy from a branch, nhánh main và thư mục / (root), rồi Save.
4. Khi GitHub triển khai xong, mở địa chỉ website được hiển thị trong Pages.

Không tải riêng tệp ZIP làm nội dung website. Hãy giải nén và tải các tệp bên trong.
Không cần cài đặt hay chạy lệnh build.

## Nội dung

- index.html: trang chủ mới nhất.
- du-an-noi-bat.html, tai-tro-dong-hanh.html, hoat-dong-cong-dong.html: các trang Dấu ấn DNY.
- danh-muc-ao-bong-chuyen.html và các trang chi-tiet-*.html.
- assets/: hình ảnh đã tách từ HTML, dùng chung để giảm dung lượng.
- Hai đường dẫn dny-demo*.html chuyển về index.html để tương thích link cũ.
